Roadmap

What's planned next — and what we're still thinking through.

Our promise: everything on this page stays 100% local. No servers, no accounts, no new data collection — ever. Roadmap items aren't dated promises; feedback and pull requests genuinely shape what ships.

Planned Exploring Shipped

Capture

Delayed capture (3s / 5s / 10s timer) Planned

Capture hover states, dropdown menus, and tooltips that disappear the moment you click the extension.

Capture straight to clipboard or download Planned

An optional "quick mode" that skips the editor for high-frequency work.

Right-click context menu capture Planned

Full page, visible area, or region — straight from the page's context menu.

Repeat last region Planned

Re-capture the previous selection rectangle — great for iterating on documentation.

Region loupe & element snapping Exploring

A magnifier at the crosshair while you drag, with edges that snap to element boundaries.

Batch capture: list of URLs → one PDF Exploring

Scroll-and-stitch multiple pages and export them as a single multi-page PDF.

Editor

Beautify mode Planned

Padding, rounded corners, drop shadow, and gradient backgrounds — polish screenshots for sharing, all in canvas.

Numbered step stamps Planned

Auto-incrementing 1, 2, 3… counters for tutorials, guides, and support replies.

Highlighter & solid-redact tools Planned

Variants on the existing rectangle and blur primitives.

Eyedropper color picker Planned

Pick annotation colors straight from the page, using the browser's native EyeDropper.

Resize / scale at export Planned

Export at 50%, a fixed width, and more — right from the export dialog.

Drag & drop any image into the editor Planned

Annotate images you already have, not just fresh captures.

Power features

Local OCR — copy text out of a screenshot Exploring

Client-side text recognition, lazy-loaded like the PDF exporter. No data ever leaves the device.

Recent captures shelf Exploring

Your last few captures kept locally and reopenable in the editor — with a clear-all control, of course.

More filename tokens Planned

{domain} and friends for the filename template engine.

Performance & polish

Worker-based stitch compositing Exploring

Move full-page stitching to a Web Worker so the UI stays buttery on very long pages.

Instant editor open Exploring

Prewarm the editor while capture runs so it opens the moment you're ready.

Выбирайте инструмент для скриншотов с открытым кодом по тому, где находится то, что вы снимаете. Для всего, что есть на экране Windows, используйте ShareX. Для рабочего стола Linux, macOS или Windows используйте Flameshot. Для веб-страниц используйте браузерный инструмент, например OpenScreenShot или встроенный в Firefox инструмент Screenshots, а для скриншотов из скрипта — shot-scraper, Playwright или Puppeteer.

OpenScreenShot — наш продукт. На этой странице сказано, где он не подходит, и она не составляет рейтинг инструментов. Все факты приведены по состоянию на 9 октября 2026 г. и взяты из репозитория, страницы в магазине или официального сайта каждого проекта; ссылки ниже.

## Какой инструмент какую платформу охватывает

| Инструмент          | Где работает                                                       | Что снимает                                                         | Лицензия      | Вся страница        | Видео                                |
| ------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------- | ------------- | ------------------- | ------------------------------------ |
| OpenScreenShot      | Chrome, Firefox                                                    | Веб-страницы во вкладке                                             | MIT           | Да                  | Запись вкладки, только версия Chrome |
| Screenity           | Chrome и браузеры на Chromium, которые используют Chrome Web Store | Записи вкладки, области, рабочего стола, окна приложения или камеры | GPL-3.0       | Не описано          | Да                                   |
| ShareX              | Windows                                                            | Всё на экране                                                       | GPL-3.0       | Съёмка с прокруткой | Видео и GIF                          |
| Flameshot           | Linux, macOS, Windows                                              | Область экрана                                                      | GPL-3.0       | Нет                 | Не описано                           |
| Firefox Screenshots | Firefox для компьютера                                             | Веб-страницы                                                        | Часть Firefox | Да                  | Не описано                           |
| shot-scraper        | Python 3.10 или новее                                              | Веб-страницы, из команды                                            | Apache-2.0    | Да, по умолчанию    | Да, из файла сценария                |
| Playwright          | Node.js, Python, Java, .NET                                        | Веб-страницы, из кода                                               | Apache-2.0    | Да                  | Да                                   |
| Puppeteer           | Node.js                                                            | Веб-страницы, из кода                                               | Apache-2.0    | Да                  | Да, Chrome                           |

Ни один из этих инструментов не работает на Android или iOS. Расширение браузера видит только веб-страницу в своей вкладке. Приложение для компьютера видит весь экран, но не знает, где заканчивается веб-страница.

## В браузере: OpenScreenShot

[OpenScreenShot](https://github.com/pghqdev/OpenScreenShot) — расширение под лицензией MIT для [Chrome](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp) и [Firefox](https://addons.mozilla.org/firefox/addon/openscreenshot/). Оно снимает всю страницу, видимую часть, выделенную область или один элемент. Затем открывается редактор со стрелками, фигурами, текстом, номерами шагов, размытием и обрезкой, а экспорт возможен в PNG, JPEG, WebP или PDF. Съёмка и правка выполняются в вашем браузере, и расширение не загружает ваши скриншоты или записи. Каждый режим описан в [документации](/ru/docs/).

Версия для Chrome также [записывает вкладку](/ru/docs/#record) с микрофоном, звуком вкладки и веб-камерой по желанию и экспортирует MP4 или WebM. Версия для Firefox только делает скриншоты.

OpenScreenShot не подходит, когда то, что вам нужно, находится за пределами вкладки браузера. Он не может снять рабочий стол, другое приложение или страницу настроек браузера и не записывает весь экран.

## Запись в браузере: Screenity

[Screenity](https://github.com/alyssaxuu/screenity) — расширение для Chrome для записи экрана и аннотаций. Оно записывает вкладку, область, рабочий стол, любое окно приложения или камеру, с микрофоном и внутренним звуком. Оно экспортирует MP4, GIF или WebM либо сохраняет в Google Drive. Можно рисовать, добавлять текст, стрелки и фигуры и размывать чувствительное содержимое страницы.

Лицензия — [GPL-3.0](https://github.com/alyssaxuu/screenity/blob/master/LICENSE). В README сказано, что лицензия сменилась на GPLv3 для версии на Manifest V3, начиная с версии 3.0.0. Расширение бесплатно, и для локальных записей вход не нужен. [Screenity Pro](https://screenity.io/pro) стоит $10 в месяц или $120 в год после 7-дневного пробного периода и добавляет редактор, отправку по ссылке и облачное хранение на серверах в ЕС, с аккаунтом. В README сказано, что некоторые части кода подключаются к Screenity Pro и что они активны только в версии из Chrome Web Store.

При установке Screenity запрашивает доступ ко всем сайтам. Его документация не описывает скриншоты всей страницы. Выбирайте его вместо OpenScreenShot, когда нужно записать рабочий стол или другое приложение; см. [альтернативы Screenity](/ru/alternatives/screenity/).

## Windows: ShareX

[ShareX](https://getsharex.com/) — бесплатное приложение для Windows без рекламы под лицензией [GPL-3.0](https://github.com/ShareX/ShareX). Оно снимает экран, окно или область, а его [съёмка с прокруткой](https://getsharex.com/docs/scrolling-screenshot) сравнивает последовательные скриншоты и добавляет изменившиеся части, так что одно изображение может содержать то, что прокручивается за пределы экрана. Оно также записывает видео и GIF, а в его README указаны OCR и сканирование QR-кодов.

В редакторе изображений есть фигуры, стрелки, текст, речевые выноски, размытие, пикселизация, выделение и spotlight. ShareX может загружать файлы во множество сервисов, а задачи после съёмки могут загружать автоматически, если вы их так настроите. Проверьте эти настройки, прежде чем снимать личное содержимое. Его можно получить как установщик, портативную сборку или из Microsoft Store или Steam. Последний релиз, v21.0.0, вышел 3 июля 2026 г.

ShareX не работает на macOS и Linux.

## Linux, macOS и Windows: Flameshot

[Flameshot](https://flameshot.org/) — бесплатный инструмент для скриншотов для Linux, macOS и Windows под лицензией [GPL-3.0](https://github.com/flameshot-org/flameshot). Вы выделяете область и сразу размечаете её стрелками, выделением, размытием или пикселизацией, текстом, линиями от руки, рамками и номерами-счётчиками. У него также есть интерфейс командной строки. В его README указана необязательная загрузка в Imgur, которую запускает клавиша Return, поэтому запомните эту клавишу, прежде чем снимать личное содержимое.

[Версия 14.0.0](https://github.com/flameshot-org/flameshot/releases/tag/v14.0.0) (июнь 2026 года) спрашивает, какой монитор снимать, и использует xdg-desktop-portal как основной способ съёмки в Linux. В README поддержка Wayland в GNOME и Plasma названа экспериментальной.

У Flameshot нет съёмки с прокруткой. [Запрос на эту функцию](https://github.com/flameshot-org/flameshot/issues/1130) всё ещё открыт. Функции записи в его документации мы не нашли. Для всей веб-страницы в Linux сочетайте Flameshot с браузерным инструментом.

## Встроенный: Firefox Screenshots

Firefox имеет открытый код, и его инструмент Screenshots не требует установки. Щёлкните правой кнопкой по странице, выберите **Take Screenshot** («Сделать скриншот») и выберите область, видимую часть или **Save full page** («Сохранить всю страницу»), согласно [руководству Mozilla](https://blog.mozilla.org/en/firefox/how-to-capture-screenshots-with-firefox/). Результат можно скопировать или скачать. Mozilla [прекратила загрузку](https://blog.mozilla.org/futurereleases/2019/01/24/clarifying-the-future-of-firefox-screenshots/) на свой сервер Screenshots в Firefox 67 (май 2019 года), поэтому снимки остаются локальными.

Для команды консоль Firefox DevTools принимает `:screenshot --fullpage`, которая сохраняет PNG в папку загрузок, согласно [документации DevTools](https://firefox-source-docs.mozilla.org/devtools-user/taking_screenshots/index.html). Фронтенд Chrome DevTools тоже имеет открытый код под лицензией [BSD-3-Clause](https://github.com/ChromeDevTools/devtools-frontend), и его команда **Capture full size screenshot** («Сделать скриншот в полном размере») сохраняет PNG. Каждый браузер описан в [руководствах по скриншотам всей страницы](/ru/full-page-screenshot/).

## Из скрипта: shot-scraper, Playwright, Puppeteer

Эти инструменты снимают веб-страницы из команды или из кода, для повторяющейся работы и CI. Они загружают страницу в собственном браузере, поэтому не видят ваши вкладки с выполненным входом.

- [shot-scraper](https://github.com/simonw/shot-scraper) — инструмент командной строки на Python на основе Playwright. По умолчанию он делает скриншоты всей страницы, а также сохраняет PDF и записывает видео по сценарию YAML.
- [Playwright](https://github.com/microsoft/playwright) — фреймворк Microsoft для автоматизации браузеров и тестирования в Chromium, Firefox и WebKit, с API для скриншотов, PDF и видео.
- [Puppeteer](https://github.com/puppeteer/puppeteer) — библиотека Google для Node.js для Chrome и Firefox, с API для скриншотов, PDF и записи MP4.

Наш собственный пакет `openscreenshot` под лицензией MIT добавляет инструмент командной строки и MCP-сервер для ИИ-агентов. Все они с командами разобраны в [сравнении для разработчиков](/ru/blog/website-screenshot-tools-for-developers/).

## Что выбрать

- **Всё на экране Windows, со съёмкой с прокруткой:** ShareX.
- **Область экрана в Linux или macOS:** Flameshot.
- **Вся веб-страница с разметкой и экспортом в PDF:** OpenScreenShot или Firefox Screenshots для быстрого снимка без установки.
- **Запись рабочего стола или другого приложения:** Screenity или ShareX в Windows.
- **Скриншоты из скрипта или CI:** shot-scraper, Playwright или Puppeteer.

Если открытый код не обязателен, [сравнение расширений для скриншотов всей страницы](/ru/blog/full-page-screenshot-extensions/) добавляет GoFullPage, FireShot и другие. [Страница сравнения](/ru/compare/) показывает OpenScreenShot, GoFullPage и FullPage Capture бок о бок.

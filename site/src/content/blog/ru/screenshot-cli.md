OpenScreenShot CLI снимает веб-страницу в PNG с помощью локально установленного браузера, совместимого с Chrome. Это отдельный пакет, не связанный с расширением для браузера. Если установлены Node.js, pnpm и Chrome, выполните:

```sh
pnpm dlx openscreenshot shot https://example.com --out screenshot.png --full
```

Команда запускает отдельный браузер без интерфейса, переходит по URL, записывает изображение и закрывает браузер. Она не подключается к вкладкам или профилю с выполненным входом в вашем обычном браузере.

## Задавайте размер окна явно

Для снимка окна не указывайте `--full`. Ширина по умолчанию — 1280 пикселей, высота — 800 пикселей. Задайте оба значения, если макету нужен определённый размер:

```sh
pnpm dlx openscreenshot shot https://example.com --out desktop.png --width 1440 --height 900
pnpm dlx openscreenshot shot https://example.com --out narrow.png --width 390 --height 844
```

Ширина принимает целые числа от 200 до 3840, высота — от 200 до 2160. Узкое окно проверяет адаптивный макет на этой ширине. Оно не эмулирует сенсорный ввод телефона, плотность пикселей устройства или мобильный браузер: CLI использует десктопный user agent.

Добавьте `--full`, чтобы снять содержимое за пределами окна. Снимок всей страницы в браузере без интерфейса отличается от реализации расширения с прокруткой и склейкой; не рассчитывайте, что каждая динамическая страница будет выглядеть одинаково в обоих случаях.

## Сохраните файл или выведите в stdout

Без `--out` команда записывает `screenshot.png` в текущую папку. Указывайте имя файла явно, чтобы артефакты было легко узнать. Создайте родительскую папку для вывода до запуска команды.

`--out -` выводит байты PNG в stdout:

```sh
pnpm dlx openscreenshot shot https://example.com --out - > screenshot.png
```

Используйте перенаправление, безопасное для двоичных данных. CLI всегда создаёт PNG; если назвать вывод `capture.jpg` или `capture.pdf`, он не будет преобразован. Для изображений с аннотациями или вывода в PDF используйте [редактор расширения](/ru/docs/#export).

## Решение частых проблем

Если Chrome не найден, установите его или задайте в `CHROME_PATH` путь к исполняемому файлу браузера. Например, в системе Linux, где Chromium установлен по этому пути:

```sh
CHROME_PATH=/usr/bin/chromium pnpm dlx openscreenshot shot https://example.com --out screenshot.png
```

Переход по адресу ждёт `networkidle2` с таймаутом 30 секунд. У текущей команды нет параметров для своего ожидания, селектора, cookie или входа в аккаунт. Успешная съёмка также не доказывает, что приложение загрузилось правильно: проверьте PNG на страницы ошибок, состояния загрузки и отсутствующие ресурсы.

Код выхода 0 означает, что команда съёмки завершилась, 1 — ошибку съёмки, 2 — неверное использование или ошибку проверки аргументов. Используйте эти коды при объединении команд в цепочку, а затем проверьте само изображение.

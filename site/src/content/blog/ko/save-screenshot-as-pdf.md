OpenScreenShot에서 스크린샷을 PDF로 저장하려면 편집기에서 캡처를 열고, **이미지 저장**을 클릭해 **내보내기** 대화상자를 연 뒤 **PDF**를 선택하세요. 상단 바의 **PDF** 버튼을 누르면 저장된 PDF 설정으로 클릭 한 번에 저장됩니다. 대화상자에서 바꾸기 전까지 기본 설정은 A4, 세로 방향, 여러 페이지입니다. 문서를 읽는 방식에 따라 이미지 한 페이지, A4 또는 Letter 레이아웃, 여러 페이지 내보내기 중에서 고르세요.

## 스크린샷 캡처하고 준비하기

웹페이지 전체가 필요하다면 [전체 페이지 캡처](/ko/blog/full-page-screenshot-chrome/)로 시작하세요. 문서에 한 부분만 들어가면 된다면 선택 영역을 사용하세요. 기존 이미지를 편집기 스테이지에 끌어다 놓고 주석을 단 뒤 내보낼 수도 있습니다.

내보내기 전에 불필요한 여백을 잘라 내고, 받는 사람에게 필요한 화살표, 텍스트, 단계 번호를 추가하세요. 개인 정보는 불투명 가리기로 덮으세요. 주석과 Beautify 프레임은 내보낸 결과에 포함되므로 저장하기 전에 확인하세요.

편집기 상단 바에서 **이미지 저장**을 클릭하거나 Windows/Linux에서는 **Ctrl+S**, macOS에서는 **⌘S**를 누른 다음, **내보내기** 대화상자에서 PDF를 선택하세요.

## 어떤 PDF 레이아웃을 써야 할까요?

### 이미지 한 페이지

스크린샷을 PDF 한 페이지에 통째로 담습니다. 받는 사람이 화면에서 문서를 확대하고 이동하며 볼 때 유용합니다. 아주 긴 캡처는 뷰어의 기본 확대 수준에서 읽기 불편할 수 있으므로, 보내기 전에 PDF 뷰어에서 확인하세요.

### A4 또는 Letter에 맞추기

스크린샷을 문서에 맞춰 넣거나 인쇄해야 할 때는 표준 용지 크기를 사용하세요. 긴 웹페이지를 한 장에 맞추면 텍스트가 작아집니다. 맞춘 결과에서 레이블을 읽을 수 없다면 중요한 부분만 잘라 내거나 여러 페이지를 사용하세요.

### 여러 페이지

여러 페이지 내보내기는 캡처를 페이지 크기의 구간으로 나눕니다. OpenScreenShot은 페이지가 나뉘는 곳에서도 내용을 따라 읽을 수 있도록 구간 사이에 5mm 겹침을 둡니다. 나뉘는 부분을 확인하세요. 내보내기는 이미지를 다루기 때문에 워드 프로세서처럼 문단을 재배치할 수는 없습니다.

## PDF 텍스트를 검색할 수 있나요?

OpenScreenShot은 스크린샷을 PDF 안의 이미지 콘텐츠로 내보냅니다. 스크린샷을 선택 가능한 텍스트로 바꾸거나 OCR 텍스트 레이어를 추가하지 않습니다. 검색 가능한 텍스트나 접근성 있는 문서 구조가 필요하다면 웹사이트 자체의 문서 내보내기 기능이 있을 경우 그것을 사용하거나, 별도의 OCR 작업을 거치세요.

스크린샷 PDF는 인터페이스 검토, 버그 보고, 시각적 기록처럼 눈에 보이는 모습이 중요할 때 유용합니다. 브라우저의 PDF로 인쇄 기능은 웹사이트가 인쇄용 스타일을 적용할 수 있어 레이아웃이 다르게 나올 수 있습니다. 렌더링된 화면이 필요한지, 사이트의 인쇄용 문서가 필요한지에 따라 고르세요.

## 저장된 파일 확인하기

실제로 내보낸 PDF를 열어 텍스트 크기, 주석, 가린 부분, 페이지 나뉨을 검토하세요. 편집기 미리보기만 보고 판단하지 마세요. PNG, JPEG, WebP에 쓰는 이미지 배율 조절은 PDF에서는 숨겨집니다. PDF 출력은 페이지 레이아웃에 맞춰 크기가 정해지기 때문입니다.

형식과 품질 설정은 [내보내기 문서](/ko/docs/#export)를 참고하세요. 문서에 개인 정보가 포함되어 있다면 공유하기 전에 [가리기 작업 흐름](/ko/blog/redact-screenshot/)을 따르세요.

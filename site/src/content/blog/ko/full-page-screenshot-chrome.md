OpenScreenShot으로 전체 페이지 스크린샷을 찍으려면 웹페이지를 열고 툴바의 확장 프로그램 아이콘을 클릭하세요. 기본 설정에서는 캡처가 바로 시작되고, 완성된 이미지가 편집기에서 열립니다. 확장 프로그램은 페이지를 스크롤하며 캡처한 구간들을 하나의 이미지로 이어 붙입니다.

## 단계별로 페이지 캡처하기

1. [Chrome 웹 스토어에서 OpenScreenShot](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp)을 설치하고 아이콘을 툴바에 고정하세요.
2. 캡처할 페이지를 여세요. 이미지에 넣고 싶지 않은 배너나 대화상자는 닫으세요.
3. 필요한 콘텐츠가 로드될 때까지 기다리세요. 이미지를 지연 로드하는 페이지라면 캡처를 시작하기 전에 필요한 부분을 한 번 스크롤해 두세요.
4. OpenScreenShot 아이콘을 클릭하세요. 캡처가 끝날 때까지 탭을 그대로 두세요.
5. 편집기에서 이미지를 확인하세요. 특히 첫 구간과 마지막 구간, 고정 내비게이션을 살펴보세요.
6. **이미지 저장**을 클릭하고 **내보내기** 대화상자에서 PNG, JPEG, WebP 또는 PDF를 선택하세요.

아이콘을 클릭했을 때 모드 선택 화면이 열리면 **전체 페이지**를 선택하세요. 어떤 동작이 실행될지는 **원클릭 Express 모드** 설정이 정합니다. 편집기가 열리지 않으면 **캡처 후** 설정을 확인하세요. 클립보드와 다운로드는 결과를 각 대상으로 바로 보냅니다.

## 전체 페이지, 보이는 영역, 선택 영역 중 무엇을 쓸까요?

**전체 페이지**는 랜딩 페이지를 검토하거나, 기사의 시각적 사본을 남기거나, 긴 설정 화면을 보여 줄 때 유용합니다. 현재 뷰포트 밖의 콘텐츠도 포함합니다.

**보이는 영역**은 스크롤 없이 지금 화면에 보이는 부분을 캡처합니다. 주변 인터페이스가 맥락으로 유용하지만 페이지의 나머지 부분은 필요 없을 때 사용하세요.

**선택 영역**은 직접 고른 사각형을 캡처합니다. 버그 보고에는 이 방법이 가장 명확한 경우가 많습니다. 고장 난 컴포넌트와, 그것이 무엇인지 알아볼 수 있을 만큼의 주변 콘텐츠를 함께 캡처하세요. 선택 조작과 단축키는 [캡처 모드 레퍼런스](/ko/docs/#modes)를 참고하세요.

## 페이지 일부가 빠지거나 반복되는 이유는?

전체 페이지 스크린샷은 페이지가 렌더링된 그대로를 기록합니다. 웹사이트가 언젠가 로드할 수 있는 모든 것을 내보내는 기능은 아닙니다. 무한 피드, 가상화된 목록, 움직이는 콘텐츠, 페이지 안에 포함된 스크롤 영역에서는 이 차이가 드러날 수 있습니다.

OpenScreenShot은 고정 헤더와 중첩된 스크롤 영역을 처리하지만, 스크롤할 때 콘텐츠를 교체하는 페이지에서는 여전히 결과가 불완전할 수 있습니다. 페이지가 안정될 때까지 기다리고, 필요한 구간을 로드한 뒤 다시 시도하세요. 끝없이 늘어나는 피드라면 중요한 영역만 캡처하세요. 브라우저 내부 페이지와 기타 보호된 화면은 확장 프로그램의 캡처를 막을 수 있습니다. [지원 및 알려진 제한 사항](/ko/support/)을 참고하세요.

## 용도에 맞는 내보내기 형식 고르기

무손실 출력이 중요한 인터페이스 텍스트와 다이어그램에는 PNG를 사용하세요. 파일 크기가 더 중요하다면 품질을 조절할 수 있는 JPEG와 WebP를 사용하세요. 문서에 첨부하려면 [스크린샷 PDF 저장 가이드](/ko/blog/save-screenshot-as-pdf/)를 따르세요.

공유하기 전에 받는 사람에게 필요 없는 정보는 지우세요. [가리기 가이드](/ko/blog/redact-screenshot/)에서 민감한 콘텐츠를 가리고 내보낸 파일을 확인하는 방법을 설명합니다. 확장 프로그램에서의 캡처와 편집은 로컬에서 처리됩니다. 내보낸 스크린샷을 다른 곳에 업로드하는 것은 사용자가 직접 결정하는 별도의 작업입니다.

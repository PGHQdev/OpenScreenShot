Para guardar una captura como PDF en OpenScreenShot, abre la captura en el editor, haz clic en **Guardar imagen** para abrir el diálogo **Exportar** y elige **PDF**. El botón **PDF** de la barra superior guarda uno con un solo clic usando tus ajustes de PDF guardados: A4, vertical y varias páginas, hasta que los cambies en el diálogo. Elige una sola página de imagen, un formato A4 o Carta, o una exportación de varias páginas según cómo se vaya a leer el documento.

## Captura y prepara la imagen

Empieza con una [captura de página completa](/es/blog/full-page-screenshot-chrome/) si necesitas la página web entera. Usa una región cuando solo una parte va en el documento. También puedes soltar una imagen existente sobre el lienzo del editor para anotarla y exportarla.

Antes de exportar, recorta los márgenes que sobran y añade las flechas, el texto o los números de paso que necesite tu lector. Tapa la información privada con un relleno opaco. Tus anotaciones y el marco Beautify aparecen en la exportación, así que revísalos antes de guardar.

Haz clic en **Guardar imagen** en la barra superior del editor, o usa **Ctrl+S** en Windows/Linux o **⌘S** en macOS, y luego elige PDF en el diálogo **Exportar**.

## ¿Qué formato de PDF conviene usar?

### Una sola página de imagen

Mantiene la captura junta en una sola página PDF. Es útil cuando alguien va a ampliar y desplazarse por el documento en pantalla. Una captura muy alta puede ser incómoda de leer con el zoom por defecto del visor, así que revísala en un visor de PDF antes de enviarla.

### Ajustar a A4 o Carta

Usa un tamaño de papel estándar cuando la captura tiene que encajar en un documento o imprimirse. Ajustar una página web larga en una sola hoja reduce el tamaño del texto. Recorta la parte que importa o usa varias páginas si el ajuste deja las etiquetas ilegibles.

### Varias páginas

Una exportación de varias páginas divide la captura en secciones del tamaño de una página. OpenScreenShot incluye un solape de 5 mm entre secciones para que el lector siga el contenido a través de un corte. Revisa esos cortes: el exportador trabaja con una imagen, así que no puede reorganizar párrafos como un procesador de textos.

## ¿Se puede buscar el texto del PDF?

OpenScreenShot exporta la captura como contenido de imagen dentro de un PDF. No convierte la captura en texto seleccionable ni añade una capa de texto OCR. Si necesitas texto con búsqueda o una estructura de documento accesible, usa la exportación de documentos del propio sitio web cuando exista, o un flujo de OCR aparte.

Un PDF de captura es útil cuando importa el aspecto visible: una revisión de interfaz, un informe de error o un registro visual. Imprimir a PDF desde el navegador puede dar un formato distinto, porque los sitios web pueden aplicar estilos de impresión. Elige según necesites la pantalla renderizada o el documento imprimible del sitio.

## Revisa el archivo guardado

Abre el PDF exportado y revisa el tamaño del texto, las anotaciones, los datos ocultos y los saltos de página. No juzgues solo por la vista previa del editor. El control de escala de imagen que se usa para PNG, JPEG y WebP se oculta para PDF, porque la salida PDF se ajusta al formato de página.

Para los ajustes de formato y calidad, consulta la [documentación de exportación](/es/docs/#export). Si el documento incluye información privada, usa el [flujo para ocultar datos](/es/blog/redact-screenshot/) antes de compartirlo.

Para salvar uma captura de tela como PDF no OpenScreenShot, abra a captura no editor, clique em **Salvar imagem** para abrir o diálogo **Exportar** e selecione **PDF**. O botão **PDF** na barra superior salva um PDF com um clique, usando suas configurações de PDF salvas: A4, retrato e várias páginas, até você alterá-las no diálogo. Escolha uma página de imagem única, um layout A4 ou Letter ou uma exportação em várias páginas, de acordo com a forma como o documento será lido.

## Capture e prepare a captura de tela

Comece com uma [captura de página inteira](/pt-br/blog/full-page-screenshot-chrome/) se você precisa da página web completa. Use uma região selecionada quando só uma parte deve entrar no documento. Você também pode soltar uma imagem existente sobre a área do editor para anotá-la e exportá-la.

Antes de exportar, recorte as margens desnecessárias e adicione as setas, os textos ou os números de passo de que seu leitor precisa. Cubra as informações privadas com um preenchimento opaco. Suas anotações e o quadro Beautify aparecem na exportação, então inspecione esses elementos antes de salvar.

Clique em **Salvar imagem** na barra superior do editor, ou use **Ctrl+S** no Windows/Linux ou **⌘S** no macOS, e escolha PDF no diálogo **Exportar**.

## Qual layout de PDF você deve usar?

### Página de imagem única

Esta opção mantém a captura inteira em uma única página PDF. Ela é útil quando alguém vai aproximar e deslocar a imagem do documento na tela. Uma captura muito alta pode ficar difícil de ler no zoom padrão do visualizador, então confira o arquivo em um visualizador de PDF antes de enviá-lo.

### Ajustar a A4 ou Letter

Use um tamanho de papel padrão quando a captura precisa caber em um documento ou ser impressa. Ajustar uma página web longa a uma única folha deixa o texto menor. Recorte a parte que importa ou use várias páginas se o ajuste deixar os rótulos ilegíveis.

### Várias páginas

Uma exportação em várias páginas divide a captura em seções do tamanho de uma página. O OpenScreenShot inclui uma sobreposição de 5 mm entre as seções para ajudar o leitor a acompanhar o conteúdo em cada quebra. Inspecione essas quebras: o exportador trabalha com uma imagem, então ele não reorganiza parágrafos como um processador de texto.

## O texto do PDF é pesquisável?

O OpenScreenShot exporta a captura como imagem dentro de um PDF. Ele não transforma a captura em texto selecionável nem adiciona uma camada de texto OCR. Se você precisa de texto pesquisável ou de uma estrutura de documento acessível, use a exportação de documentos do próprio site quando ela existir, ou um fluxo de OCR separado.

Um PDF de captura de tela é útil quando a aparência visível importa: uma revisão de interface, um relatório de bug ou um registro visual. O fluxo de imprimir como PDF do navegador pode gerar um layout diferente, porque os sites podem aplicar estilos de impressão. Escolha conforme a sua necessidade: a tela renderizada ou o documento para impressão do site.

## Confira o arquivo salvo

Abra o PDF exportado e revise o tamanho do texto, as anotações, os dados ocultos e as quebras de página. Não julgue só pela prévia do editor. O controle de escala de imagem usado para PNG, JPEG e WebP fica oculto para PDF, porque a saída em PDF se ajusta ao layout da página.

Para as configurações de formato e qualidade, veja a [documentação de exportação](/pt-br/docs/#export). Se o documento tiver informações privadas, use o [fluxo para ocultar dados](/pt-br/blog/redact-screenshot/) antes de compartilhar.

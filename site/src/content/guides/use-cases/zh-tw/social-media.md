要在社群媒體上分享截圖，請把它裁切到能說明重點的部分，遮住個人資訊，加上外框，並以保持清晰的尺寸匯出。在 OpenScreenShot 中，用**裁切**修剪，用**模糊**的**實色**填色遮住細節，用「**Beautify（美化）**」面板加上邊距、圓角、陰影和背景。然後以 200 % 或精確的像素寬度匯出 PNG。

## 逐步為貼文準備截圖

1. 擷取網頁。右鍵選單中的**選取區域**或**擷取元素**一開始就能產生邊界緊貼的圖片。
2. 在**編輯器**中選擇**裁切**（`C`），在要保留的部分上拖曳，再點**套用**。
3. 選擇**模糊**（`B`），在**遮蔽**下選擇**實色**，蓋住姓名、大頭貼、電子郵件地址，以及任何不該由你分享的內容。
4. 點頂欄中的 **Beautify（美化）**。選擇一種**風格**，再調整**邊距**、**圓角**、**陰影**和**背景**。
5. 點**儲存圖片**。在**匯出**對話框中選擇 **PNG**，並把**縮放比例**設為 200 % 或精確的寬度。
6. 發布前，開啟儲存的檔案，檢查遮蔽和外框。

不想儲存檔案就直接發布時，點**複製**或按 `Ctrl+C`（macOS 上是 `⌘C`），再把圖片貼到貼文中。複製的圖片包含外框。

## 先遮住個人資訊

在加外框和匯出之前先完成遮蔽，並在儲存的檔案中再檢查一次。留言、追蹤者名稱、通知數量、網頁內的瀏覽器分頁和帳戶選單，常常會顯示比你預期更多的內容。

柔和的模糊或馬賽克可能留下短文字的線索。**實色**會在匯出檔中完全蓋住該區域。[遮蔽指南](/zh-tw/blog/redact-screenshot/)說明如何留邊界蓋住區域，以及如何檢查結果。

## 選擇外框

「**Beautify（美化）**」面板在[說明文件](/zh-tw/docs/#annotate)中稱為美化，提供六種風格：

- **簡潔**：帶柔和陰影的簡單外框
- **寬鬆**：截圖周圍有額外空間
- **緊湊**：貼合的外框
- **平面**：直角，沒有陰影
- **海報**：圓角，帶深陰影
- **去背**：有陰影，沒有背景

選擇風格後，可以用滑桿調整邊距、圓角半徑和陰影。**背景**可選擇六種漸層之一（墨黑、珊瑚、暮色、薄荷、沙色、天空）、單色或**透明**。外框會即時預覽，並包含在每次匯出中。

透明背景需要 PNG 或 WebP。JPEG 不支援透明，所以會用單色填滿背景。

## 以清晰的尺寸匯出

在**縮放比例**下選擇 25、50、100 或 200 %，或輸入精確的像素寬度。小區域的擷取被網站在貼文中放大時，可能看起來模糊；200 % 能給網站更多像素。超過 Chrome 畫布上限的尺寸會被拒絕，對話框會告訴你，而不是儲存空檔案。

PNG 能讓介面文字保持清晰。JPEG 和 WebP 有品質控制，可產生較小的檔案。每個社群網站都有自己的尺寸和壓縮規則，所以發布前請檢查貼文預覽。

## 箭頭和標籤

圖片的重點無法一眼看出時，加上一個**箭頭**（`A`）或簡短的**文字**（`T`）標籤。**Spotlight（聚光）**（`O`）會讓單一區域以外的部分全部變暗，很適合在繁雜的介面中突顯單一功能。註解要少，因為貼文預覽通常很小。

## 限制

擴充功能只擷取網頁內容。它不包含瀏覽器工具列或你的桌面。在你發布或上傳圖片之前，擷取和編輯內容都留在你的電腦上；你發布到的網站有自己的儲存和分享規則。

[匯出參考](/zh-tw/docs/#export)列出所有格式。要製作教學用的截圖，請參閱[用於文件的截圖](/zh-tw/use-cases/documentation/)。要製作產品的短片，請參閱[產品示範影片](/zh-tw/use-cases/product-demos/)。

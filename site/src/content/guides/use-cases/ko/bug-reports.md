버그 리포트에는 문제가 보이는 페이지 부분만 캡처하고, 잘못된 곳을 표시하고, 이미지를 이슈에 붙여넣기 전에 개인 정보를 가리세요. OpenScreenShot에서는 캡처에 **선택 영역**이나 **요소 캡처**를, 표시에 **화살표**와 **단계 번호** 도구를, 가리기에 **단색** 채우기를 쓴 **블러**를 사용해요. 스크린샷에는 주소 표시줄 없이 페이지 콘텐츠만 보이므로 URL, 브라우저, 재현 단계는 이슈 본문에 적으세요.

## 버그를 캡처하고 표시하는 단계

1. 페이지를 열고 문제가 생기는 상태로 만드세요. 문제를 가리는 배너는 닫으세요.
2. 페이지를 마우스 오른쪽 버튼으로 클릭하고 **OpenScreenShot** 하위 메뉴를 연 뒤 **선택 영역**이나 **요소 캡처**를 고르세요. 기본 설정에서는 툴바 아이콘을 클릭하면 대신 전체 페이지를 캡처해요.
3. 영역의 경우, 문제 주변에 위치를 알아볼 수 있을 만큼 인터페이스를 넣어 사각형을 드래그하세요. `Enter`를 눌러 확정하세요. 요소의 경우, 원하는 카드, 표, 양식에 윤곽선이 생길 때까지 마우스를 올린 뒤 클릭하거나 `Enter`를 누르세요.
4. **편집기**에서 문제가 있는 부분에 **화살표**(`A`)를 넣으세요. 버그를 재현하는 데 여러 번 클릭해야 한다면 각 동작마다 **단계 번호**(`S`)를 넣으세요.
5. **블러**(`B`)를 선택하고 **가리기**에서 **단색**을 고른 뒤 액세스 토큰, 이메일 주소, 계정 이름, 내부 호스트 이름을 덮으세요.
6. **복사**를 클릭하거나 `Ctrl+C`(macOS에서는 `⌘C`)를 누르고 이미지를 이슈에 붙여넣으세요.

요소 모드에서 `↑`는 부모 요소를, `↓`는 자식 요소를 선택해요. 윤곽선이 너무 작거나 너무 큰 래퍼에 잡힐 때 도움이 돼요. 요소가 전부 보이지 않으면 선택기가 대신 전체 페이지 캡처를 제안해요.

## 호버 상태, 드롭다운, 툴팁 캡처

메뉴나 툴팁은 다른 곳을 클릭하면 닫히는 경우가 많아요. 팝업이나 **설정**에서 **지연**을 3초, 5초, 10초로 설정하고 캡처를 시작한 뒤, 툴바 배지의 카운트다운이 끝나기 전에 메뉴를 여세요.

지연은 영역 선택이 시작되기 전에 실행되므로 드래그하다가 메뉴가 닫힐 수 있어요. 호버 상태는 지연을 건 **보이는 영역**으로 캡처하고 나중에 **자르기**(`C`)로 잘라내세요. 영역을 한 번 선택한 뒤 오른쪽 클릭 메뉴의 **영역 반복**을 지연과 함께 쓸 수도 있어요. 다시 드래그하지 않고 같은 사각형을 캡처해요.

## 클립보드 동작으로 편집기 건너뛰기

표시가 필요 없는 스크린샷이라면 팝업이나 **설정**에서 **캡처 후**를 **클립보드**로 설정하세요. 그러면 캡처할 때마다 바로 클립보드로 들어가고 툴바 배지가 이를 확인해 줘요. `Ctrl+V` 또는 `⌘V`로 이미지를 이슈에 붙여넣으세요.

이 설정은 키보드 단축키와 오른쪽 클릭 메뉴에도 적용돼요. 주석을 달거나 가려야 할 때는 다시 **편집기**로 바꾸세요. 클립보드 캡처는 가리기 단계를 건너뛰므로 캡처하기 전에 페이지에 개인 정보가 없는지 확인하세요.

## 스크린샷 옆에 적을 내용

스크린샷은 무엇이 잘못됐는지 보여 줘요. 이슈 본문은 개발자가 문제를 재현하는 데 필요한 맥락을 줘요.

- 개인 쿼리 매개변수를 지운 페이지 URL
- 브라우저 이름과 버전, 운영 체제
- 이미지의 단계 번호와 같은 순서로 적은 재현 단계
- 예상한 결과와 실제로 일어난 일
- 페이지가 실시간 데이터를 보여 준다면 문제가 생긴 시각

스크린샷 하나에는 문제 하나만 담으세요. 같은 이미지에 두 번째 버그가 있으면 화살표가 어느 쪽을 가리키는지 불분명해져요.

## 제한 사항

블러와 모자이크는 픽셀을 흐리게 하지만 짧은 텍스트의 단서를 남길 수 있어요. **단색**은 내보낸 결과에서 영역을 완전히 덮어요. [가리기 가이드](/ko/blog/redact-screenshot/)에서 결과를 확인하는 방법을 설명해요. 브라우저 내부 페이지와 그 밖의 보호된 페이지는 확장 프로그램의 캡처를 막아요. [지원 및 알려진 제한 사항](/ko/support/)을 참고하세요.

[캡처 모드 레퍼런스](/ko/docs/#modes)에서 선택 컨트롤을, [주석 레퍼런스](/ko/docs/#annotate)에서 모든 도구와 단축키를 볼 수 있어요. 문제를 신고한 사용자에게 답할 때는 [고객 지원용 스크린샷](/ko/use-cases/customer-support/)을 참고하세요. 버그를 움직이는 화면으로 보여 주려면 [제품 데모 영상](/ko/use-cases/product-demos/)을 참고하세요.

디자인 리뷰에는 **전체 페이지**로 페이지 전체를 캡처하고, 피드백을 받고 싶은 지점을 표시하고, 검토자가 페이지별로 읽을 수 있는 PDF로 공유하세요. OpenScreenShot에서는 **Spotlight**가 논의 중인 영역 밖을 모두 어둡게 하고, **텍스트**와 **화살표**로 설명을 달아요. 리뷰 대상이 카드, 차트, 표 같은 컴포넌트 하나라면 **요소 캡처**를 사용하세요.

## 리뷰용 페이지를 준비하는 단계

1. 리뷰할 창 너비로 페이지를 여세요. 캡처는 현재 너비의 레이아웃을 보여 주므로, 다른 브레이크포인트를 리뷰하려면 먼저 창 크기를 바꾸세요.
2. 지연 로딩되는 이미지가 불러와지도록 한 번 끝까지 스크롤한 뒤 맨 위로 돌아가세요. 리뷰와 관계없는 쿠키 배너와 채팅 위젯은 닫으세요.
3. OpenScreenShot 아이콘을 클릭하세요. 기본 설정에서는 **전체 페이지** 캡처가 시작돼요. 편집기가 열릴 때까지 탭을 그대로 두세요.
4. 첫 구역과 마지막 구역, 헤더, 캐러셀처럼 움직임이 있는 영역을 확인하세요.
5. **Spotlight**(`O`)를 선택하고 검토자가 볼 영역마다 드래그하세요. 여러 개의 컷아웃은 하나의 어두운 레이어로 합쳐져요.
6. 각 영역 옆에 **텍스트**(`T`) 메모를 넣고, 메모가 작은 세부 사항을 가리켜야 하는 곳에는 **화살표**(`A`)를 넣으세요.
7. **이미지 저장**을 클릭해 **내보내기** 대화상자를 여세요. **PDF**를 고른 뒤 아래의 내보내기 단계를 따르세요.

## 컴포넌트 하나 캡처하기

페이지를 마우스 오른쪽 버튼으로 클릭하고 **OpenScreenShot** 하위 메뉴를 연 뒤 **요소 캡처**를 고르세요. 컴포넌트에 윤곽선이 생길 때까지 마우스를 올린 뒤 클릭하거나 `Enter`를 눌러 그 경계대로 캡처하세요. `↑`를 누르면 카드를 담은 구역 같은 부모 요소를 선택하고, `←`나 `→`를 누르면 이웃 요소로 이동해요.

요소 캡처는 수동으로 자르지 않아도 꼭 맞는 이미지를 줘서, 같은 컴포넌트의 두 버전을 비교할 때 유용해요. 요소가 화면에 전부 보이지 않으면 선택기가 대신 전체 페이지 캡처를 제안해요.

## 검토자가 따라올 수 있게 피드백 표시하기

Spotlight 컷아웃은 사각형, 둥근 사각형, 타원 중에서 고를 수 있어요. 주제 하나에 Spotlight 이미지 하나를 쓰세요. 밝은 영역이 많은 이미지는 어느 메모가 어느 영역에 해당하는지 검토자가 추측하게 만들어요. 번호를 매긴 피드백이라면 각 지점에 **단계 번호**(`S`)를 넣고 리뷰 스레드에서 그 번호를 언급하세요. 번호는 자동으로 올라가고, 하나를 지우면 다시 매겨져요.

**도형** 도구(`R`)는 페이지의 나머지를 어둡게 하지 않고 영역 주위에 윤곽선을 그려요. **화살표** 도구는 채운 머리, 열린 머리, 양쪽 머리, 점 머리를 제공하고, 가운데 핸들을 드래그해 다른 콘텐츠를 피해 구부릴 수 있어요.

## PDF로 리뷰 공유하기

**내보내기** 대화상자에서 **PDF**를 고르고, **페이지 크기**에서 **A4**나 **Letter**를 선택한 뒤 **여러 페이지로 나누기**를 켜세요. 이어지는 페이지가 5mm씩 겹치므로 페이지 경계에 걸린 텍스트 줄은 두 페이지에 모두 보여요. 화면에서 읽을 용도로 페이지를 하나의 긴 PDF 페이지로 유지하려면 **페이지 크기**에서 **전체**를 고르세요.

PDF에는 스크린샷이 주석과 함께 이미지로 들어 있어요. 선택할 수 있는 텍스트는 없어요. [스크린샷 PDF 저장 가이드](/ko/blog/save-screenshot-as-pdf/)에서 레이아웃을 비교하고, [내보내기 레퍼런스](/ko/docs/#export)에서 다른 형식을 볼 수 있어요.

## 전체 페이지 캡처의 제한 사항

전체 페이지 캡처는 확장 프로그램이 스크롤하는 동안 렌더링되는 페이지를 기록해요. 일부 콘텐츠는 그 스크롤 중에 바뀌어요.

- 고정 헤더는 첫 타일에서 캡처되어 맨 위에 한 번만 들어가요. 사이드바나 하단 바 같은 다른 고정 요소가 예상한 위치에 나오는지 확인하세요.
- 화면에 들어올 때만 불러와지는 이미지는 캡처가 먼저 도달하면 빈 상자로 보일 수 있어요. 캡처하기 전에 페이지를 스크롤하세요.
- 캐러셀, 애니메이션, 실시간 카운터, 무한 피드는 타일 사이에 바뀔 수 있어요. 일시정지하거나, 대신 중요한 영역만 캡처하세요.

높이가 32,000 기기 픽셀을 넘는 페이지는 최대 여섯 개의 이미지로 저장되고, 각 이미지는 별도의 편집기 탭에서 열려요. [전체 페이지 스크린샷 가이드](/ko/blog/full-page-screenshot-chrome/)에서 더 많은 문제 해결 방법을 다뤄요. 도움말 문서에 들어갈 스크린샷은 [문서용 스크린샷](/ko/use-cases/documentation/)을 참고하세요.

웹 페이지의 시각적 사본을 남기려면 **전체 페이지**로 캡처하고 파일 이름에 날짜와 사이트를 넣어 PNG나 PDF로 저장하세요. OpenScreenShot은 페이지를 스크롤하고, 부분들을 하나의 이미지로 이어 붙이고, 파일을 컴퓨터에 저장해요. 스크린샷은 화면에서 페이지가 어떻게 보였는지를 기록해요. 페이지가 진본이었다거나 바뀌지 않았다는 증거는 되지 않아요.

## 페이지 사본을 저장하는 단계

1. 팝업이나 툴바 아이콘의 오른쪽 클릭 메뉴에서 **설정**을 여세요. **파일 이름 템플릿**을 `{date}`와 `{domain}`이 들어간 패턴으로 설정하세요. 예: `Archive/{domain}/{date}_{title}`.
2. 페이지를 여세요. 지연 로딩되는 이미지와 댓글이 불러와지도록 한 번 끝까지 스크롤한 뒤 맨 위로 돌아가세요.
3. OpenScreenShot 아이콘을 클릭하세요. 기본 설정에서는 **전체 페이지** 캡처가 시작되고 결과가 **편집기**에서 열려요.
4. 맨 위, 맨 아래, 그리고 스크롤할 때 불러와지는 구역을 확인하세요.
5. **이미지 저장**을 클릭하세요. **내보내기** 대화상자에서 **PNG**나 **PDF**를 고르고, 파일 이름을 확인한 뒤 **내보내기**를 클릭하세요.

편집기 없이 저장하려면 **설정**에서 **캡처 후**를 **다운로드**로 설정하세요. 그러면 캡처할 때마다 템플릿에 따라 이름이 붙은 PNG로 다운로드 폴더에 바로 저장돼요.

## PNG와 PDF 중 어느 것?

캡처의 모든 픽셀을 그대로 남기려면 **PNG**를 고르세요. 무손실이라 인터페이스 텍스트가 선명하게 유지되고, 어떤 이미지 뷰어로든 열 수 있어요.

사본을 문서 폴더에 넣거나 인쇄해야 한다면 **PDF**를 고르세요. **페이지 크기**에서 **전체**는 이미지 크기에 맞춘 한 페이지를 만들어요. **A4**나 **Letter**에 **여러 페이지로 나누기**를 켜면 긴 캡처를 5mm씩 겹치는 페이지로 나눠요. PDF에는 스크린샷이 이미지로 들어 있어서 텍스트를 검색하거나 선택할 수 없어요. [스크린샷 PDF 저장 가이드](/ko/blog/save-screenshot-as-pdf/)에서 레이아웃을 비교해요.

## 나중에 찾을 수 있게 파일 이름 짓기

파일 이름 템플릿에는 다음 토큰을 쓸 수 있어요.

- `{date}`: 컴퓨터 시계 기준 YYYY-MM-DD 형식의 날짜
- `{time}`: HHMMSS 형식의 시각
- `{domain}`: `www.`를 뺀 사이트 호스트 이름
- `{title}`: 파일 이름에 쓸 수 없는 문자를 바꾼 페이지 제목
- `{w}`와 `{h}`: 픽셀 단위의 이미지 너비와 높이

템플릿에 `/`를 넣으면 다운로드 폴더 안의 폴더에 저장돼요. 그래서 `Archive/{domain}/{date}_{title}`은 사본을 사이트별로, 그다음 날짜별로 정리해요. **설정**의 실시간 미리보기에서 캡처하기 전에 결과를 볼 수 있어요.

## 아주 긴 페이지

이미지 하나에는 높이 32,000 기기 픽셀까지의 페이지가 들어가요. 그보다 긴 페이지는 최대 여섯 개의 이미지로 저장돼요. **다운로드**에서는 각 부분이 템플릿 이름에 `_part1of3` 같은 접미사가 붙어 저장돼요. **편집기**나 **클립보드**에서는 각 부분이 별도의 편집기 탭에서 열리고, 거기서 하나씩 내보내요.

이미지 여섯 개로도 담을 수 없을 만큼 긴 페이지는 오류와 함께 거부돼요. 이 경우 필요한 구역을 **보이는 영역**이나 **선택 영역**으로 캡처하세요. [전체 페이지 스크린샷 가이드](/ko/blog/full-page-screenshot-chrome/)에서 중첩된 스크롤 영역이나 고정 헤더 같은 다른 경우를 다뤄요.

## 스크린샷이 보여 줄 수 있는 것과 없는 것

스크린샷은 한순간 브라우저에 보인 것을 시각적으로 기록한 것이에요. 서명이나 변조 확인 기능이 없고, 누구나 이미지 파일을 편집할 수 있어요. `{date}` 토큰은 파일 이름을 지을 때 컴퓨터 시계에서 가져와요. 페이지가 특정 형태로 존재했다는 증거가 필요하다면 그 목적에 맞게 만들어진 서비스를 사용하고, 스크린샷은 개인 참고용으로 보관하세요.

전체 페이지 캡처는 페이지가 렌더링하지 않은 콘텐츠도 놓쳐요. 접힌 구역, 페이지의 다른 탭, 스크롤한 지점 너머의 무한 피드, 열지 않은 로그인 뒤의 콘텐츠가 그래요.

## 사본이 저장되는 곳

OpenScreenShot은 브라우저 안에서 캡처를 처리하고 기기의 로컬 저장소에 저장해요. 서버에 업로드하지 않아요. 내보낸 파일은 다운로드 폴더로 가요. 공유하거나 업로드하기 전까지는 컴퓨터에 남아 있고, 업로드하는 서비스에는 그 서비스의 저장 규칙이 있어요. 자세한 내용은 [개인정보처리방침](/ko/privacy/)을 참고하세요.

[설정 레퍼런스](/ko/docs/#settings)에서 파일 이름 템플릿을 다뤄요. 동료를 위해 캡처에 표시를 하려면 [디자인 리뷰용 페이지 캡처](/ko/use-cases/design-review/)를 참고하세요.

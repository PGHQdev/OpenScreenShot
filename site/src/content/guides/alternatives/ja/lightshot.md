Chrome や Firefox でウェブページのスクリーンショットを撮り、ページ全体のキャプチャ、ぼかし、PDF 書き出しを使いたい、しかもファイルをデバイス上にとどめたいなら、OpenScreenShot に切り替えてください。ほかのアプリやデスクトップ全体をキャプチャするなら、Lightshot のままで構いません。Lightshot には Windows と Mac 用のデスクトップ アプリがあり、OpenScreenShot がキャプチャするのはブラウザ内のウェブページだけです。すぐに発行される短縮リンクに頼っている場合も、Lightshot のままで構いません。OpenScreenShot にはアップロード サービスがないため、キャプチャは貼り付けるかファイルを添付して共有します。

OpenScreenShot は私たちの製品です。このページの Lightshot に関する情報は 2026年10月9日時点のもので、[Chrome ウェブストア の掲載ページ](https://chromewebstore.google.com/detail/mbniclmhobmnbdlbpiphghaielnnpgdp)、[ウェブサイト](https://app.prntscr.com/en/index.html)、[Firefox アドオンのページ](https://addons.mozilla.org/firefox/addon/lightshot/)、Google の更新サーバーから取得したバージョン 7.0.1 のマニフェストに基づいています。

## Lightshot と OpenScreenShot の比較

|                                 | Lightshot                                                         | OpenScreenShot                                        |
| ------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------- |
| 価格                            | 無料                                                              | 無料                                                  |
| オープンソース                  | いいえ（独自ライセンス）                                          | はい、MIT                                             |
| インストール時のサイト アクセス | すべてのウェブサイト（`*://*/*` が必須）                          | なし。キャプチャを開始したときに現在のタブにアクセス  |
| ページ全体のキャプチャ          | いいえ。掲載ページでは範囲選択を説明                              | はい                                                  |
| 注釈とぼかし                    | その場で編集                                                      | 図形、矢印、テキスト、手順番号、ぼかし、切り抜き      |
| PDF の書き出し                  | いいえ                                                            | はい                                                  |
| タブの録画                      | いいえ                                                            | はい、Chrome で（Firefox 版はスクリーンショットのみ） |
| アカウントやクラウド            | 短縮リンク用に prnt.sc へ任意でアップロード。ディスクへの保存も可 | アカウント不要、アップロードなし                      |
| デスクトップのキャプチャ        | はい、Windows と Mac のアプリで                                   | いいえ                                                |

Lightshot の Chrome 拡張機能の最終更新は 2024年7月23日です。

## アップロードと共有リンク

Lightshot はスクリーンショットを prnt.sc にアップロードし、短縮リンクを発行できます。アップロードされた画像の閲覧にアカウントは不要です。2021 年、[Kaspersky は](https://www.kaspersky.com/blog/cryptoscam-in-lightshot/39224/) URL が連番になっているため 1 文字変えると別の画像が開くことがあり、"Anyone can see published screenshots without authentication."（公開されたスクリーンショットは認証なしで誰でも見られます）と報告しました。同じ年に [AIN.UA も](https://en.ain.ua/2021/09/08/lightshot-allows-people-to-view-screenshots-of-other-users)同じ問題を報じています。2026 年の時点でこれが当てはまるかどうかは、私たちは確認していません。

OpenScreenShot にはアップロードの手順がありません。キャプチャをブラウザ内で処理して保存し、書き出したファイルはダウンロード フォルダに保存されます。どこかに貼り付けるか添付するまで、キャプチャは誰にも見られません。詳しくは[プライバシーのセクション](/ja/docs/#privacy)を参照してください。

## 変わらないこと

範囲を手早くキャプチャする操作はそのままです。`Ctrl+Shift+E`（macOS では `⌘⇧E`）を押すか、ページを右クリックして**選択範囲**を選び、矩形をドラッグして `Enter` を押します。矢印、テキスト、図形、蛍光ペンを備えたエディタが開きます。**コピー**で画像がクリップボードに入り、そのままチャットに貼り付けられます。

エディタを省略するには、**キャプチャ後**を**クリップボード**にします。キャプチャはそのままクリップボードに送られるため、キャプチャして貼り付けるだけの使い方に近くなります。

## 変わること

ページのより広い範囲をキャプチャできます。**ページ全体**はスクロールしてページ全体を 1 枚の画像につなぎ合わせます。**要素をキャプチャ**は 1 つのカード、表、グラフをその範囲どおりにキャプチャします。**表示領域**はタブの画面に表示されている部分をキャプチャします。

エディタには**ぼかし**（`B`）があり、弱いぼかし、モザイク、非公開のデータを完全に覆う**塗りつぶし**を選べます。**手順番号**のバッジは自動で番号が増えます。**画像を保存**をクリックすると**書き出し**ダイアログが開き、PNG、JPEG、WebP、PDF で保存できます。

インストール時のアクセスは少なくなります。OpenScreenShot は `activeTab` を使い、一度に 1 つのタブにだけアクセスします。ブラウザの設定ページ、拡張機能のページ、ブラウザの外にあるものはキャプチャできません。デスクトップ アプリやほかのプログラムのウィンドウには、引き続きデスクトップ用のツールが必要です。

## 切り替え方

1. [Chrome ウェブストア](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp) または [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/openscreenshot/) から OpenScreenShot をインストールします。
2. アイコンをツールバーに固定します。
3. 最初のキャプチャを試します。初期設定の**ワンクリック Express モード**では、アイコンをクリックすると**ページ全体**のキャプチャが始まります。範囲をキャプチャするには、`Ctrl+Shift+E` または右クリック メニューを使います。
4. **設定**で**キャプチャ後**を設定します。すぐに貼り付けるなら**クリップボード**、注釈を付けるなら**エディタ**、PNG を保存するなら**ダウンロード**です。
5. ほかのプログラム用にデスクトップのスクリーンショット アプリを使い続ける場合は、OpenScreenShot と同じキーを使っていないか確認してください。Chrome では、`chrome://extensions/shortcuts` で拡張機能のキーを変更できます。

サポートの返信に使う手早い画像については、[カスタマー サポート用のスクリーンショット](/ja/use-cases/customer-support/)を参照してください。投稿用には、[SNS 用のスクリーンショット](/ja/use-cases/social-media/)を参照してください。デスクトップのキャプチャが必要な場合は、デスクトップ ツールで何ができるかを [Snagit の代替](/ja/alternatives/snagit/)のページで確認してください。

Snagit でキャプチャするものの大半がウェブページなら、OpenScreenShot に切り替えてください。ページ全体のキャプチャ、注釈、マスク処理、PDF 書き出し、タブ録画をブラウザ内で、無料かつサインインなしで行えます。デスクトップ アプリ、プログラムのウィンドウ、画面全体をキャプチャするなら、Snagit のままで構いません。Snagit は Windows と macOS 用のデスクトップ アプリで、OpenScreenShot は設計上、ブラウザ内のウェブページだけをキャプチャします。Snagit には、システム音声と画面全体の録画、プログラムのウィンドウ内のスクロール キャプチャ、メールアドレス、電話番号、クレジット カード情報をぼかすか隠せる Smart Redact もあります。OpenScreenShot にはこれらの機能はありません。

OpenScreenShot は私たちの製品です。このページの Snagit に関する情報は 2026年10月9日時点のもので、TechSmith の [Snagit のページ](https://www.techsmith.com/snagit/)、[ストアのページ](https://www.techsmith.com/store/snagit)、[サブスクリプション料金に関するサポート記事](https://support.techsmith.com/hc/en-us/articles/27009223314701-TechSmith-Transition-to-Annual-Subscription-Pricing-Model-in-2025)に基づいています。

## 変わらないこと

ウェブページについては、主な作業をそのまま引き継げます。**ページ全体**はページをスクロールして 1 枚の画像につなぎ合わせます。**選択範囲**は矩形をキャプチャし、**要素をキャプチャ**は 1 つのカード、表、グラフをその範囲どおりにキャプチャします。**エディタ**には、曲げられる矢印、図形、テキスト、番号付きの**手順番号**のバッジ、蛍光ペン、重要な部分以外をすべて暗くする **Spotlight** があります。**切り抜き**と **Cut** で画像を切り詰めます。ツールの一覧は[注釈のリファレンス](/ja/docs/#annotate)で確認できます。

PDF の書き出しとクリップボードへのコピーもそのまま使えます。**画像を保存**をクリックすると**書き出し**ダイアログが開き、PNG、JPEG、WebP、PDF で保存できます。**コピー**をクリックすると、画像を文書に貼り付けられます。**Beautify** パネルは、余白、角丸、影、背景を追加してフレーム付きの画像にします。

## 変わること

OpenScreenShot では、非公開の項目を自分で 1 つずつ覆います。**ぼかし**（`B`）を選び、**マスク**で**塗りつぶし**を選んで、各項目の上をドラッグします。塗りつぶしは書き出した画像で範囲を完全に覆います。保存したファイルの確認方法は[マスク処理のガイド](/ja/blog/redact-screenshot/)で説明しています。

録画の対象は Chrome の 1 つのブラウザ タブです。ポップアップで**録画**をクリックし、**マイク**、**タブの音声**、**ウェブカメラ**をオンにして、タブ全体またはドラッグした範囲を録画します。録画エディタはクリックごとに 2 倍のズームを追加し、MP4 または WebM で書き出します。ほかのアプリのシステム音声や画面全体の録画には対応していません。[録画のリファレンス](/ja/docs/#record)を参照してください。

キャプチャはデバイス上にとどまり、アカウントやクラウドのライブラリはありません。ほかのツールで撮ったキャプチャに注釈を付けるには、画像をエディタにドロップするか、`Ctrl+V`（macOS では `⌘V`）で貼り付けます。貼り付けた画像でも、キャプチャと同じようにエディタを使えます。

## 切り替え方

1. [Chrome ウェブストア](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp) または [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/openscreenshot/) から OpenScreenShot をインストールします。
2. アイコンをツールバーに固定します。
3. 長いページでアイコンをクリックします。初期設定の**ワンクリック Express モード**では、これで**ページ全体**のキャプチャが始まり、**エディタ**が開きます。
4. **設定**で**キャプチャ後**を設定します。注釈を付けるなら**エディタ**、すぐに貼り付けるなら**クリップボード**、PNG を保存するなら**ダウンロード**です。
5. `{date}` や `{title}` などのトークンを使って**ファイル名テンプレート**を設定します。
6. デスクトップの作業用に Snagit を使い続ける場合は、そのキーが OpenScreenShot と重ならないようにしてください。Chrome では、`chrome://extensions/shortcuts` で拡張機能のキーを変更できます。

手順番号を使ったヘルプ記事については、[ドキュメント用のスクリーンショット](/ja/use-cases/documentation/)を参照してください。ページへのレビューのメモについては、[デザイン レビュー用にページをキャプチャする方法](/ja/use-cases/design-review/)を参照してください。デスクトップのキャプチャにも対応した無料のツールについては、[Lightshot の代替](/ja/alternatives/lightshot/)のページを参照してください。

Chrome または Firefox が動くどの OS でも、ページ全体のスクリーンショットにブラウザ内で無料で注釈やぼかしを入れたい、しかもコードを読めるものがよいなら、OpenScreenShot に切り替えてください。リンクが機能する PDF、一括キャプチャや自動キャプチャ、高度な PDF 書き出しやキャプチャ履歴などの FireShot Pro の追加機能が必要なら、FireShot のままで構いません。OpenScreenShot は PDF を画像として保存するため、文字は検索できず、リンクも機能しません。キャプチャするのはウェブページだけで、デスクトップのウィンドウや画面全体はキャプチャしません。

OpenScreenShot は私たちの製品です。このページの FireShot に関する情報は 2026年10月9日時点のもので、[Chrome ウェブストア の掲載ページ](https://chromewebstore.google.com/detail/mcbpblocgmgfnpjjppndjkmgjaogfceg)、[ウェブサイト](https://getfireshot.com/)、[購入ページ](https://getfireshot.com/buy.php)、[Firefox アドオンのページ](https://addons.mozilla.org/en-US/firefox/addon/fireshot/)、Google の更新サーバーから取得したバージョン 2.1.4.18 のマニフェストに基づいています。

## FireShot と OpenScreenShot の比較

| オープンソース                  | いいえ（独自ライセンス）                                                                                                                          | はい、MIT                                                             |

| ページ全体のキャプチャ          | はい                                                                                                                                              | はい                                                                  |
| 注釈とぼかし                    | 掲載ページにはテキスト、矢印、ぼかしの記載あり。Pro には "Editor & smart annotations (on Windows)"（エディタとスマート注釈（Windows））の記載あり | 無料、ブラウザ内で                                                    |

## 変わらないこと

どちらのツールでも、キャプチャはローカルにとどまります。FireShot のサイトには "100% local captures keep your work private and offline-safe."（100% ローカルのキャプチャで、作業内容を非公開かつオフラインでも安全に保ちます）とあります。OpenScreenShot はキャプチャをブラウザ内で処理し、アップロードしません。Chrome では、どちらもインストール時にすべてのサイトへのアクセスを求めません。

長いページのページ全体のキャプチャと、PNG、JPEG、PDF への書き出しはそのまま使えます。OpenScreenShot は WebP でも保存できます。

## 変わること

エディタはブラウザのタブで動くため、どの OS でも同じように動作し、すべてのツールが無料です。**矢印**、**テキスト**、**手順番号**、**Spotlight** で細部を示し、**ぼかし**（`B`）の**塗りつぶし**で非公開のデータを隠します。**切り抜き**と **Cut** で長いキャプチャを切り詰めます。ツールの一覧は[注釈のリファレンス](/ja/docs/#annotate)で確認できます。

PDF の動作は異なります。**画像を保存**をクリックして**書き出し**ダイアログを開き、**PDF** を選びます。**全体**では画像に合わせたサイズの 1 ページになります。**A4** または **Letter** で**複数ページに分割**をオンにすると、長いキャプチャを 5 mm ずつ重なるページに分割します。PDF にはスクリーンショットが画像として入るため、クリックできるリンクや選択できる文字はありません。読者がリンクをたどる PDF を送るなら、その用途には FireShot のほうが向いています。

OpenScreenShot には、一括キャプチャ、キャプチャ履歴、メールや OneNote へのアップロードはありません。その代わりに、**要素をキャプチャ**、フレーム付きの画像にする **Beautify** パネル、クリック位置でのズームと MP4 書き出しを備えた Chrome でのタブ録画があります。

FireShot の Chrome 版のマニフェストは `nativeMessaging` を必須としています。これにより、拡張機能はコンピューターにインストールされたプログラムと通信できます。OpenScreenShot はネイティブ プログラムを使いません。タブのキャプチャのオプション権限を Chrome が求めるのは、初めて**録画**をクリックしたときだけです。

FireShot の Firefox アドオンの最終更新は 2023年6月5日で、すべてのウェブサイト上のデータへのアクセスを求めます。OpenScreenShot の Firefox 版はインストール時にサイトへのアクセスを求めず、スクリーンショットだけに対応しています。

## 切り替え方

1. [Chrome ウェブストア](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp) または [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/openscreenshot/) から OpenScreenShot をインストールします。
2. アイコンをツールバーに固定します。
3. 長いページでアイコンをクリックします。初期設定の**ワンクリック Express モード**では、これで**ページ全体**のキャプチャが始まり、**エディタ**が開きます。
4. **設定**で**キャプチャ後**を設定します。各キャプチャを PNG としてそのままダウンロード フォルダに保存するなら**ダウンロード**を、すぐに貼り付けるなら**クリップボード**を選びます。
5. `{date}`、`{domain}`、`{title}` などのトークンを使って**ファイル名テンプレート**を設定します。`/` を入れると Downloads 内のフォルダに保存されます。

キーボード ショートカットでキャプチャが始まらない場合は、`chrome://extensions/shortcuts` を開き、ほかの拡張機能が同じキーを使っていないか確認してください。

日付入りのページのコピーについては、[ウェブページの見た目をコピーとして保存する方法](/ja/use-cases/archive-web-pages/)を参照してください。注釈付きのキャプチャを使ったヘルプ ページについては、[ドキュメント用のスクリーンショット](/ja/use-cases/documentation/)を参照してください。形式と倍率は[書き出しのリファレンス](/ja/docs/#export)で説明しています。ほかのページ全体のキャプチャ ツールについては、[GoFullPage の代替](/ja/alternatives/gofullpage/)と [FullPage Capture の代替](/ja/alternatives/fullpage-capture/)を参照してください。

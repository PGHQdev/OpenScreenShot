Snagit으로 캡처하는 대상이 대부분 웹 페이지라면 OpenScreenShot으로 바꾸세요. 브라우저 안에서 전체 페이지 캡처, 표시, 가리기, PDF 내보내기, 탭 녹화를 무료로, 로그인 없이 해요. 데스크톱 앱, 프로그램 창, 화면 전체를 캡처한다면 Snagit을 계속 쓰세요. Snagit은 Windows와 macOS용 데스크톱 앱이고, OpenScreenShot은 설계상 브라우저 안의 웹 페이지만 캡처해요. Snagit은 시스템 오디오와 전체 화면도 녹화하고, 프로그램 창 안에서 스크롤하며, 이메일, 전화번호, 신용카드 정보를 블러 처리하거나 가릴 수 있는 Smart Redact를 제공해요. OpenScreenShot에는 이 기능들이 없어요.

OpenScreenShot은 저희 제품이에요. 이 페이지의 Snagit 관련 사실은 2026년 10월 9일 기준이며, TechSmith의 [Snagit 페이지](https://www.techsmith.com/snagit/), [스토어 페이지](https://www.techsmith.com/store/snagit), [구독 가격에 관한 지원 문서](https://support.techsmith.com/hc/en-us/articles/27009223314701-TechSmith-Transition-to-Annual-Subscription-Pricing-Model-in-2025)에서 가져왔어요.

저희 위치에서는 TechSmith 스토어 페이지의 미국 달러 가격을 불러올 수 없어서, 이 페이지에는 가격을 적지 않았어요. 해당 지역의 [스토어 페이지](https://www.techsmith.com/store/snagit)를 확인하세요.

## 그대로인 것

웹 페이지라면 주요 작업이 그대로 이어져요. **전체 페이지**는 페이지를 스크롤하면서 하나의 이미지로 이어 붙여요. **선택 영역**은 사각형을 캡처하고, **요소 캡처**는 카드, 표, 차트 하나를 정확한 경계대로 캡처해요. **편집기**에는 곡선 경로 화살표, 도형, 텍스트, 번호가 매겨지는 **단계 번호** 배지, 형광펜, 그리고 중요한 부분 외에 모두 어둡게 하는 **Spotlight**가 있어요. **자르기**와 **Cut**으로 이미지를 다듬어요. [주석 레퍼런스](/ko/docs/#annotate)에서 도구 목록을 볼 수 있어요.

PDF 내보내기와 클립보드 복사도 그대로예요. **이미지 저장**을 클릭해 PNG, JPEG, WebP, PDF용 **내보내기** 대화상자를 열거나, **복사**를 클릭해 이미지를 문서에 붙여넣으세요. **Beautify** 패널은 프레임을 입힌 이미지를 위해 여백, 둥근 모서리, 그림자, 배경을 넣어요.

## 달라지는 것

OpenScreenShot에서는 개인 정보 항목을 하나씩 직접 덮어야 해요. **블러**(`B`)와 **가리기**의 **단색** 채우기를 고른 뒤 각 항목 위를 드래그하세요. 단색은 내보낸 결과에서 영역을 완전히 덮어요. [가리기 가이드](/ko/blog/redact-screenshot/)에서 저장된 파일을 확인하는 방법을 보여 줘요.

녹화 범위는 Chrome의 브라우저 탭 하나예요. 팝업에서 **녹화**를 클릭하고, **마이크**, **탭 오디오**, **웹캠**을 켠 뒤 탭 전체나 드래그한 영역을 녹화하세요. 녹화 편집기는 클릭마다 2배 줌을 넣고, MP4나 WebM으로 내보내요. 다른 앱의 시스템 오디오와 전체 화면 녹화는 없어요. [녹화 레퍼런스](/ko/docs/#record)를 참고하세요.

캡처는 기기에 남고, 계정이나 클라우드 라이브러리가 없어요. 다른 도구로 만든 캡처에 주석을 달려면 이미지를 편집기에 끌어다 놓거나 `Ctrl+V`(macOS에서는 `⌘V`)로 붙여넣으세요. 편집기는 붙여넣은 이미지에서도 캡처와 똑같이 동작해요.

## 바꾸는 방법

1. [Chrome 웹 스토어](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp)나 [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/openscreenshot/)에서 OpenScreenShot을 설치하세요.
2. 아이콘을 툴바에 고정하세요.
3. 긴 페이지에서 아이콘을 클릭하세요. 기본값인 **원클릭 Express 모드**에서는 **전체 페이지** 캡처가 시작되고 **편집기**가 열려요.
4. **설정**에서 **캡처 후**를 정하세요. 주석을 달려면 **편집기**, 바로 붙여넣으려면 **클립보드**, PNG를 저장하려면 **다운로드**를 고르세요.
5. `{date}`와 `{title}` 같은 토큰으로 **파일 이름 템플릿**을 정하세요.
6. 데스크톱 작업용으로 Snagit을 계속 쓴다면, 그 키가 OpenScreenShot과 겹치지 않는지 확인하세요. Chrome에서는 `chrome://extensions/shortcuts`에서 확장 프로그램의 키를 바꿀 수 있어요.

단계 번호가 들어간 도움말 문서는 [문서용 스크린샷](/ko/use-cases/documentation/)을 참고하세요. 페이지에 리뷰 메모를 다는 방법은 [디자인 리뷰용 페이지 캡처](/ko/use-cases/design-review/)를 참고하세요. 데스크톱 캡처도 지원하는 무료 도구는 [Lightshot 대안](/ko/alternatives/lightshot/) 페이지를 참고하세요.

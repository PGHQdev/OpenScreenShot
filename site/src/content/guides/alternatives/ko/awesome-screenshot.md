브라우저 안에서 캡처하고 녹화하며 모든 것을 기기에 남기고 싶고, 모든 편집기 도구를 요금제 제한 없이 무료로 쓰고 싶다면 OpenScreenShot으로 바꾸세요. 공유 링크, 클라우드 저장소, Professional 요금제에서 최대 4K의 데스크톱·카메라 녹화 같은 클라우드 기능이 필요하다면 Awesome Screenshot을 계속 쓰세요. OpenScreenShot에는 공유 링크도 클라우드도 없어요. Chrome에서만 브라우저 탭 하나를 녹화하고, 데스크톱 창이나 화면 전체는 캡처하지 않아요.

OpenScreenShot은 저희 제품이에요. 이 페이지의 Awesome Screenshot 관련 사실은 2026년 10월 9일 기준이며, [Chrome 웹 스토어 페이지](https://chromewebstore.google.com/detail/nlipoenfbbikpbjkfpfillcgkoblgpmj), [가격 페이지](https://www.awesomescreenshot.com/pricing), [Firefox 부가 기능 페이지](https://addons.mozilla.org/en-US/firefox/addon/screenshot-capture-annotate/), Google 업데이트 서버의 버전 4.4.44 매니페스트에서 가져왔어요.

## Awesome Screenshot과 OpenScreenShot 비교

|                     | Awesome Screenshot                                                  | OpenScreenShot                                       |
| ------------------- | ------------------------------------------------------------------- | ---------------------------------------------------- |
| 가격                | 무료 요금제. Basic은 월 $5부터, Professional은 월 $6부터(연간 결제) | 무료, 유료 요금제 없음                               |
| 오픈 소스           | Firefox 페이지에는 MPL 2.0으로 표시. 공개 소스 저장소는 찾지 못함   | 예, MIT, 소스 공개                                   |
| 설치 시 사이트 접근 | 모든 웹사이트(필수 `<all_urls>`, 모든 페이지에 콘텐츠 스크립트)     | 없음. 캡처를 시작할 때 현재 탭에 접근                |
| 전체 페이지 캡처    | 예                                                                  | 예                                                   |
| 주석과 블러         | 예. 무료 요금제는 기본 도구, 유료 요금제는 모든 도구                | 모든 도구 무료                                       |
| PDF 내보내기        | 예                                                                  | 예                                                   |
| 탭 녹화             | 예, 데스크톱과 카메라도                                             | 예, 탭만, Chrome에서(Firefox 버전은 스크린샷만 캡처) |
| 계정 또는 클라우드  | 클라우드 저장소와 공유 링크. 로컬 저장도 제공                       | 계정 없음, 업로드 없음                               |

## 요금제 제한

Awesome Screenshot 무료 요금제는 스크린샷 최대 100개, 기본 주석, 720p 녹화 최대 20개를 제공해요. 로컬 저장에서는 스크린샷이 무제한이고 녹화는 최대 5분이에요. Basic은 연간 결제 시 월 $5, 월간 결제 시 $6이에요. Professional은 연간 결제 시 월 $6, 월간 결제 시 $8이고, 녹화 무제한에 최대 4K예요.

OpenScreenShot의 요금제는 하나예요. 모든 캡처 모드, 편집기 도구, 내보내기 형식이 무료이고, 만들어야 할 계정도 없어요.

## 그대로인 것

전체 페이지, 보이는 영역, 영역 캡처와 함께 도형, 화살표, 텍스트, 형광펜, 블러가 있는 편집기를 그대로 쓸 수 있어요. PNG, JPEG, PDF 내보내기도 그대로예요. Chrome에서는 마이크와 웹캠을 넣은 탭 녹화도 그대로예요.

## 달라지는 것

캡처가 기기에 남아요. OpenScreenShot은 캡처를 로컬 브라우저 저장소에, 녹화를 IndexedDB에 저장하고 업로드하지 않아요. Chrome 웹 스토어의 Awesome Screenshot 개인정보 섹션은 "Website content"(웹사이트 콘텐츠) 수집을 공개해요. OpenScreenShot 캡처를 공유하려면 **복사**를 클릭하고 이미지를 붙여넣거나, **이미지 저장**을 클릭하고 파일을 첨부하세요. 자세한 내용은 [개인정보 섹션](/ko/docs/#privacy)에 있어요.

설치 시 접근 범위가 더 좁아요. OpenScreenShot은 `activeTab`으로 한 번에 탭 하나에만 접근해요. Chrome은 **녹화**를 처음 클릭할 때 선택 사항인 탭 캡처 권한을 요청하고, **여러 사이트에서 녹화**를 켤 때만 모든 사이트 접근을 요청해요.

레코더는 탭 하나에서 동작해요. 팝업에서 **녹화**를 클릭하고, **마이크**, **탭 오디오**, **웹캠**을 고른 뒤 **탭 전체**를 그대로 두거나 드래그해서 페이지 일부를 녹화하세요. 중지하면 녹화 편집기가 클릭마다 2배 줌을 넣어요. 트리밍하고, 웹캠 버블을 배치하고, MP4나 WebM으로 내보낼 수 있어요. [녹화 레퍼런스](/ko/docs/#record)를 참고하세요.

가리기에는 **단색** 채우기를 쓴 **블러**(`B`)를 사용하세요. 내보낸 결과에서 영역을 완전히 덮어요.

## 바꾸는 방법

1. [Chrome 웹 스토어](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp)나 [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/openscreenshot/)에서 OpenScreenShot을 설치하세요.
2. 아이콘을 툴바에 고정하세요.
3. 긴 페이지에서 아이콘을 클릭하세요. 기본값인 **원클릭 Express 모드**에서는 **전체 페이지** 캡처가 시작되고 **편집기**가 열려요. **보이는 영역**, **선택 영역**, **요소 캡처**는 페이지를 마우스 오른쪽 버튼으로 클릭하고 **OpenScreenShot** 하위 메뉴를 열어 쓰세요.
4. **설정**에서 **캡처 후**를 **편집기**, **클립보드**, **다운로드** 중 하나로 정하세요.
5. Awesome Screenshot 사용을 그만두기 전에 클라우드 저장소에서 보관할 캡처와 영상을 다운로드하세요. 예전 이미지에 주석을 달려면 OpenScreenShot 편집기에 끌어다 놓으세요.

기능을 보여 주는 짧은 영상은 [제품 데모 영상](/ko/use-cases/product-demos/)을 참고하세요. 지원 답변용 스크린샷은 [고객 지원용 스크린샷](/ko/use-cases/customer-support/)을 참고하세요. 클라우드 링크가 있는 레코더를 비교하고 있다면 [Loom 대안](/ko/alternatives/loom/)과 [Nimbus 대안](/ko/alternatives/nimbus/)을 참고하세요.

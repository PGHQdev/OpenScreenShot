В Firefox есть встроенный инструмент Screenshots. Нажмите `Ctrl+Shift+S` (`Cmd+Shift+S` на macOS), выберите **Save full page** (сохранить всю страницу), затем выберите **Download** (скачать), чтобы сохранить PNG, или **Copy** (копировать), чтобы поместить изображение в буфер обмена. Дополнение OpenScreenShot для Firefox добавляет редактор для стрелок, текста и скрытия данных и экспортирует в PNG, JPEG, WebP или PDF.

## Встроенный способ

Mozilla описывает этот инструмент в статье [Take screenshots in Firefox](https://support.mozilla.org/en-US/kb/take-screenshots-firefox).

1. Откройте страницу, которую хотите снять.
2. Нажмите `Ctrl+Shift+S` в Windows и Linux или `Cmd+Shift+S` в macOS. Можно также нажать правой кнопкой на пустое место страницы и выбрать **Take Screenshot** (сделать скриншот).
3. Выберите **Save full page** в правом верхнем углу.
4. В предпросмотре выберите **Download**, чтобы сохранить PNG в папку загрузок Firefox, или выберите **Copy**.

Предпросмотр предлагает **Copy** и **Download**. Чтобы добавить стрелки или текст, откройте PNG в другом приложении.

В Firefox DevTools есть второй способ. Откройте Web Console и введите `:screenshot --fullpage`, и Firefox сохранит PNG всей страницы. Можно также включить кнопку **Take a screenshot of the entire page** (сделать скриншот всей страницы) в разделе **Available Toolbox Buttons** (доступные кнопки панели инструментов) в настройках DevTools. Mozilla описывает оба способа в своём [руководстве по скриншотам в DevTools](https://firefox-source-docs.mozilla.org/devtools-user/taking_screenshots/index.html).

## Ограничения

- **Размер.** Firefox обрезает снимок больше 32 766 пикселей по одной стороне или 472 907 776 пикселей по площади и показывает «Your screenshot was cropped because it was too large» (скриншот обрезан, потому что он слишком большой). Сообщение Firefox об ошибке для слишком большого снимка приводит другие числа: меньше 32 700 пикселей по самой длинной стороне или 124 900 000 пикселей по общей площади.
- **Масштаб экрана.** Firefox считает эти ограничения в физических пикселях: ширина и высота страницы, умноженные на коэффициент пикселей экрана. На экране 2x ограничение высоты страницы в CSS-пикселях вдвое меньше, около 16 383.
- **Внутренние области прокрутки.** Firefox берёт границы всей страницы из ширины и высоты прокрутки окна. Когда страница прокручивает панель внутри оболочки фиксированной высоты, содержимое этой панели не разворачивается, поэтому снимок показывает только одну высоту экрана.
- **Отложенная загрузка.** Изображения с `loading="lazy"` загружаются, только когда вы прокручиваете к ним. Прокрутите страницу перед съёмкой, иначе части изображения могут остаться пустыми.
- **Бесконечная прокрутка.** У ленты, которая подгружает содержимое при прокрутке, нет настоящего низа. Снимок содержит только то, что загрузилось до начала съёмки.
- **Закреплённые шапки.** Перед отправкой проверьте верх и середину изображения: шапка может отсутствовать, повторяться или стоять не на своём месте.

## С OpenScreenShot

Версия OpenScreenShot для Firefox делает только скриншоты. Запись вкладки есть в версии для Chrome. Её режим всей страницы прокручивает страницу, снимает её по частям и склеивает части в одно изображение, ставя фиксированные шапки один раз сверху. Страницы, где прокручивается внутренний элемент, а не окно, тоже работают.

1. Установите [OpenScreenShot из Firefox Add-ons](https://addons.mozilla.org/firefox/addon/openscreenshot/) и закрепите его значок на панели инструментов.
2. Откройте страницу и прокрутите её один раз, чтобы загрузились отложенные изображения, затем вернитесь наверх.
3. Нажмите на значок OpenScreenShot и выберите **Вся страница**, если откроется меню режимов.
4. Проверьте результат в редакторе, особенно верх, низ и закреплённую навигацию.
5. Нажмите **Сохранить изображение** и выберите PNG, JPEG, WebP или PDF либо нажмите **Копировать**.

Firefox использует `Ctrl+Shift+S` для своего инструмента Screenshots, поэтому для OpenScreenShot нажимайте на значок на панели инструментов. [Справка по режимам съёмки](/ru/docs/#modes) описывает каждый режим, а [справка по экспорту](/ru/docs/#export) — форматы и масштаб.

## Что выбрать

- Используйте Firefox Screenshots для быстрого PNG страницы, которая прокручивает всё окно и укладывается в ограничение размера.
- Используйте команду `:screenshot --fullpage`, если вы уже работаете в Web Console.
- Используйте OpenScreenShot для страниц с прокручиваемой внутренней панелью и для снимков, которые нужно разметить или сохранить в PDF, как в [баг-репортах](/ru/use-cases/bug-reports/) или для [сохранённой копии страницы](/ru/use-cases/archive-web-pages/).

[Руководство по Chrome](/ru/full-page-screenshot/chrome/) и [руководство по Edge](/ru/full-page-screenshot/edge/) описывают ту же задачу в браузерах на Chromium, где OpenScreenShot также умеет записывать вкладки. О страницах, которые блокируют расширения, например о настройках Firefox, см. [поддержку и известные ограничения](/ru/support/).

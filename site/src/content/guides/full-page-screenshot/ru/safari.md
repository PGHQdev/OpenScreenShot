В Safari на Mac нет команды для скриншота всей страницы. Ближайший встроенный вариант — PDF: выберите **File** > **Print** (Файл > Напечатать), нажмите **PDF** внизу диалога и сохраните файл. Для файла изображения Web Inspector в Safari может снять один элемент страницы. Версии OpenScreenShot для Safari нет. Safari устанавливает Safari Web Extensions из Mac App Store и не может устанавливать пакеты из Chrome Web Store или дополнения Firefox. На Mac OpenScreenShot работает в Chrome, Firefox, Edge и других браузерах.

## Встроенный способ

### Сохранить страницу в PDF

Apple описывает этот способ в статье [Print or create a PDF of a webpage in Safari](https://support.apple.com/guide/safari/print-or-create-a-pdf-of-a-webpage-ibrw1060/18.0/mac/15.0).

1. Откройте страницу, которую хотите сохранить.
2. Прокрутите страницу один раз, чтобы загрузились изображения, которые подгружаются поздно.
3. Выберите **File** > **Print**.
4. Чтобы сохранить цвета страницы, включите в параметрах печати печать фоновых изображений и цветов. Можно также добавить веб-адрес и дату в колонтитулы.
5. Нажмите **PDF** внизу диалога и сохраните файл.

### Снять элемент в Web Inspector

1. Выберите **Safari** > **Settings** > **Advanced** (Safari > Настройки > Дополнения) и отметьте **Show features for web developers** (показывать функции для веб-разработчиков). WebKit объясняет это в статье [Enabling Web Inspector](https://webkit.org/web-inspector/enabling-web-inspector/).
2. Откройте страницу и нажмите `Option+Cmd+I`, чтобы открыть Web Inspector.
3. На вкладке **Elements** (элементы) нажмите правой кнопкой на узел, например `<html>` или `<body>`, и выберите **Capture Screenshot** (сделать снимок экрана).
4. Safari сохранит снимок этого узла в файл.

Apple не описывает, включает ли снимок `<html>` содержимое ниже видимой части страницы и в каком формате изображения он записывается. Проверьте файл, прежде чем на него полагаться.

## Ограничения

- **Нет изображения всей страницы.** Ни один из способов не даёт такой скриншот, какой даёт инструмент для снимков всей страницы. PDF — это версия страницы для печати, а пункт Web Inspector снимает один узел.
- **Макет для печати.** PDF использует макет для печати, поэтому страница в файле может выглядеть иначе, чем на экране. Включите фоновые изображения и цвета, если дизайн от них зависит.
- **Отложенная загрузка.** Изображения с `loading="lazy"` загружаются, только когда вы прокручиваете к ним. Прокрутите страницу перед печатью или съёмкой, иначе части могут остаться пустыми.
- **Внутренние области прокрутки.** Разработчики сообщают, что автоматические снимки всей страницы в WebKit, движке Safari, показывают только одну высоту экрана, когда страница прокручивает панель внутри оболочки фиксированной высоты. Проверяйте такие страницы внимательно.
- **Закреплённые шапки.** Проверьте результат: шапка может отсутствовать, повторяться или стоять не на своём месте.

## С OpenScreenShot

OpenScreenShot недоступен для Safari. Если на том же Mac есть Chrome, Firefox, Edge, Brave, Opera, Vivaldi или Arc, откройте страницу там и используйте расширение. Chrome и другие браузеры на Chromium устанавливают его из [Chrome Web Store](https://chromewebstore.google.com/detail/hdabbojjccojlapnfjpdppcpfcnhgmdp). Firefox устанавливает его из [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/openscreenshot/).

1. Установите OpenScreenShot в другом браузере и закрепите его значок на панели инструментов.
2. Откройте страницу и нажмите на значок. В Chrome съёмку всей страницы также запускает `⌘⇧S`.
3. Проверьте результат в редакторе.
4. Нажмите **Сохранить изображение** и выберите PNG, JPEG, WebP или PDF.

Расширение прокручивает страницу, склеивает части в одно изображение и ставит фиксированные шапки один раз сверху. Страница выше 32 000 физических пикселей сохраняется в виде не более чем шести изображений. [Руководство по Chrome](/ru/full-page-screenshot/chrome/) и [руководство по Firefox](/ru/full-page-screenshot/firefox/) дают шаги для каждого браузера, включая их собственные встроенные инструменты.

## Что выбрать

- Используйте **File** > **Print** > **PDF** в Safari, чтобы сохранить читаемую копию статьи или страницы с чеком.
- Используйте **Capture Screenshot** в Web Inspector для изображения одной части страницы, например карточки или графика.
- Используйте OpenScreenShot в другом браузере на Mac для изображения всей страницы, которое можно разметить, или для PDF страницы в том виде, в каком она выглядит на экране. [Руководство по сохранению скриншота в PDF](/ru/blog/save-screenshot-as-pdf/) сравнивает раскладки PDF, а [сохранение визуальной копии страницы](/ru/use-cases/archive-web-pages/) описывает имена файлов и хранение.

По другим вопросам см. [поддержку и известные ограничения](/ru/support/).

# Browser marks

`firefox.svg` is Mozilla's Firefox browser logo, from
https://github.com/mozilla/gecko-dev/blob/master/browser/branding/official/content/about-logo.svg.
It identifies the Firefox install links. Firefox and its logo are Mozilla trademarks.

`chrome.svg` reuses the project’s Chrome glyph from
`site/src/components/ChromeIcon.astro`. It identifies the Chrome Web Store link.
Chrome and its logo are Google trademarks.

`edge.svg`, `brave.svg`, and `chromium.svg` are browser marks from
[Browser Logos](https://github.com/alrra/browser-logos/tree/main/src), in the
respective `edge`, `brave`, and `chromium` directories.
`arc.png` is the icon served by [Arc’s official website](https://arc.net/favicon.png).
These marks identify compatible browsers in the README; their trademarks belong
to their respective owners.
